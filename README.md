# EXPERT SYSTEM 2K
WEB DIAGNOSA KELISTRIKAN STARTER MOTOR MATIC INTERAKTIF

Sebuah website diagnosa kelistrikan pada starter motor matic yang interaktif bagi pengguna. Website ini merupakan inovasi teknologi berbasis Machine Learning yang mendiagnosis masalah kelistrikan starter motor matic menggunakan metode penalaran Forward dan Backward Chaining. Metode tersebut digunakan dalam bidang Kecerdasan Tiruan/Buatan (Artificial Intelligence) untuk menarik kesimpulan dari sekumpulan fakta dan aturan pada permasalahan tertentu.
